# VoxPrep — React AI Mock Interview Studio

A responsive React + Vite conversion of the supplied VoxPrep HTML concept.

## Run in VS Code
1. Install Node.js (LTS).
2. Extract the ZIP and open this folder in VS Code.
3. Open the terminal in this folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite (usually http://localhost:5173).

## Included
- Demo sign-in and personal dashboard
- Mock interview practice with role selection, text answers, speech playback and browser speech recognition
- Aptitude, web, Python and communication quizzes
- Study abroad preparation section
- Communication practice and speech input
- Searchable interview question bank
- Progress history stored in browser localStorage
- Responsive mobile layout

## Notes
This is a front-end demo. Sign-in is not secure authentication and there is no backend or live AI model. Interview feedback and scores are simple practice indicators. Browser speech recognition varies by browser/device; Chrome is recommended. Voice input requires microphone permission. Do not enter sensitive personal information.
